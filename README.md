# 净读 CleanRead

净读 CleanRead 是一款界面专业、开箱即用的网页阅读器浏览器扩展。输入网址或点击悬浮按钮，即可抓取正文、去掉广告和干扰，一键导出干净的 Markdown / 纯文本，供阅读、写作、AI 使用。

## 功能

- 一键提取当前页正文，去除广告与无关模块
- 支持多链接批量处理、本页链接采集与嵌套链接采集
- 输出 Markdown / 纯文本 / JSON / HTML，支持复制与下载
- 素材采集：可开关获取图片、视频、附件文档（PDF/Word/Excel/PPT），逐项保存、删除，或“全部获取”一次抓齐
- 一键识别图片文字（OCR）：对抓取的图片素材直接识别并追加到正文与导出内容
- 收藏夹：常用网站与链接收藏，AI 一键整理分类加标签，按使用频率自动排序，也可手动调整顺序、搜索快速查找
- AI 智能：提取正文关键词（含解释）、一键内容分类，由大模型完成
- 历史记录、收藏、语音朗读、深浅主题
- 百度文库支持：Word / Excel / PDF / PPT 文档正文提取；PPT 与扫描版 PDF 自动提供页面图片并可用 OCR 识别图中文字
- 自媒体常用站适配：小红书（笔记需登录，登录后“提取当前页”完整提取）、抖音（未登录提取标题/简介/封面）、B 站视频、微博头条文章、微信公众号、今日头条、百家号、优酷、知乎、1688 电商详情页（图文+主图视频）
- 学生查答案 / 学习站适配：百度知道、作业帮（zybang/zuoyebang）、搜狗问问、百度百科、CSDN、arXiv 文献、百度文库（Word/Excel/PDF/PPT，配合图片文字识别）
- 安全验证识别：遇到 CSDN 等站点的人机验证页会明确提示，而不是把验证页当正文
- 死链与登录墙识别：小红书已删除/404 笔记、微博失效文章、页面重定向等不再误报为“提取成功”，会明确提示“不存在/已删除/需登录”
- 计费：免费版每天 3 篇；会员 9.9 元/月包月不限量（到期自动续费，余额不足自动停止）；OCR / AI 按积分包计费

## 安装（Chrome / Edge / 360 等 Chromium 浏览器）

1. 下载安装包：`release/cleanread-v1.0.0-chromium.zip`
2. 解压到任意目录（例如 `D:\cleanread`）
3. 打开浏览器扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions/`
   - Edge：地址栏输入 `edge://extensions/`
   - 360 浏览器：`360se://extensions/`（或设置 → 扩展程序）
4. 打开右上角“开发者模式”
5. 点击“加载已解压的扩展程序”，选择解压后的目录
6. 固定“净读CleanRead”图标即可使用

## 使用

- **提取当前页**：在任意网页上点击右下角悬浮的“读”按钮，或点击扩展图标 → “提取当前页”（快捷键 Alt+C）
- **批量处理**：扩展弹窗 → “批量处理链接”，每行粘贴一个链接
- **嵌套采集**：扩展弹窗 → “采集本页内链接”，勾选目标链接后批量处理
- **图片文字识别**：在处理前勾选“图片文字识别（默认关闭）”，识别结果会追加到正文
- **素材采集**：提取前在“获取内容”勾选图片 / 视频 / 附件文档，或点“全部获取”一次抓齐；提取后正文下方“素材”面板可逐项保存、删除，图片可一键识别文字
- **失败重试与补抓**：提取失败的链接可在队列中点“重试”；已提取的内容可点右侧“重新获取素材”补抓图片/视频/附件；顶部“＋”一键新建任务
- **收藏夹**：顶部“📑”打开；支持收藏当前网站/链接、搜索、AI 整理分类、上移下移、编辑标签、按使用次数自动排序
- **AI 智能**：正文下方“提取关键词”“内容分类”；关键词带解释，点击可再次获取解释（需连接 AjkAPI，按积分计费）
- **导出**：阅读器右侧选择 Markdown / 纯文本 / JSON / HTML，复制或下载
- **百度文库**：先在浏览器中打开文库文档页，再点悬浮“读”按钮即可提取；或直接把文库链接粘贴到输入框处理
- **优酷 / 1688 等站点**：优酷提取标题、简介与封面图素材；1688 提取商品标题、属性说明、主图/详情图与主图视频，素材可直接保存
